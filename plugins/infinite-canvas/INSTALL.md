# 无限画布安装说明

## 兼容版本

- VideoFree Studio `2.0.1` 至 `2.x`。
- 本插件是应用级画布宿主，通过 VideoFree Studio 统一接口运行已安装普通插件的能力和动作，不直接解析 ComfyUI 工作流。

## 模型

无宿主自带生成模型。生成/后处理插件节点所需模型由对应普通插件的 `INSTALL.md` 声明；画布扩展节点的依赖由各自节点包声明。

## ComfyUI 节点

无。具体自定义节点由安装的无限画布节点插件声明和安装。

## 其他依赖

无额外 Python 包或系统程序。插件 UI 已构建在 `ui/dist/`，安装时不需要 Node.js。

智能体节点使用以下二选一服务：

- VideoFree Studio 已配置的系统 LLM；
- 用户自行提供的 OpenAI 兼容 Chat Completions 地址、API Key 与模型名。

自定义 API Key 按用户选择直接写入画布工作流 JSON，以便迁移和分享时保持配置完整。导出文件包含明文 Key，必须按密钥文件保管；公开分享前应手工清空。

## 安装

1. 将完整的 `infinite-canvas` 文件夹复制到 `plugins/`。
2. 普通生成插件和资源级后处理动作会自动显示，不要复制到 `canvas-nodes`。应用插件、项目工具和 workspace 业务动作不会显示。
3. 仅把条件、资源读取、数据变换等真正独立的画布节点安装到 `plugins/canvas-nodes/<package-id>/`。
4. 排空正在运行的任务并重启 VideoFree Studio 网关。
5. 打开工作台的“无限画布”。左侧“生成插件/后处理插件”来自能力与资源动作目录，“画布扩展”来自 `canvas-nodes`。

## 工作流文件与示例

- 插件附带的可复制示例位于 `plugins/infinite-canvas/work/examples/`，每个示例都是一个独立的 `.json` 文件。
- 可以像 ComfyUI 一样，把单个无限画布 JSON 直接拖入画布；导入会创建新的浏览器草稿，不覆盖当前工作流。
- 工作流 JSON 不得和媒体文件混拖；不符合协议的文件会被拒绝并显示原因。
- 用户正式保存的工作流仍按项目隔离写入项目运行时插件目录的 `work/`，不是插件源码的 `work/examples/`。
- 分享前请检查 JSON 中是否保存了自定义 LLM API Key，并手动删除敏感信息。

## 验证

- `GET /api/v2/plugins` 中存在 `infinite-canvas` 应用。
- `GET /api/v2/capabilities?operation=generate` 和 `operation=postprocess` 返回普通插件能力。
- `GET /api/v2/plugin-actions?automation=true` 返回动作目录；画布只采用 `scope: resource` 的后处理动作。
- `GET /api/v2/canvas-nodes` 只返回已安装的画布专属节点；没有安装时 `items` 为空，不影响普通插件节点显示。
- 顶部“项目资源”使用框架资源选择器；资源管理器中的“引用”会直接在画布添加资源输入节点。
- 图片、视频、音频文件可拖入画布或通过顶部导入按钮加入当前项目资源库。临时上传 ID 不会写入工作流。
- 新建工作流后可保存、重新读取并导出 JSON。
- “基础节点”按输入、媒体、数据、流程控制、输出与预览分类。图片、视频、声音和数据预览连接生成结果后会在上游完成时立即显示，不等待整个工作流；预览结果仍可继续连接后续节点。
- “智能节点”提供一个通用智能体。默认系统 LLM 只显示技能、LLM 来源和一个“角色与任务”文本框；选择自定义 API 后才显示 URL、Key 和模型。温度、Token 和超时由插件预设。
- “LLM 条件判断”分别接收原始产物和判断文本。成功端口原样传递图片、视频、音频、任务或数据；失败端口可直接回连重做目标，未接次数控制时会持续循环直到成功或用户停止。
- 如需上限，将失败端口连接“次数控制”的触发端口，再把“继续”回连重做目标，并把“结束”连接失败处理节点；“最大循环次数”由用户设置，只计算重做、不包含首次执行，不存在插件内置的隐藏上限。
- 后处理插件声明 `target_size/dimensions` 时，画布与工作台显示相同的分辨率档位；第一档为默认值，最终宽高根据来源任务自动计算。
- 顶部“+”创建浏览器草稿，草稿按项目自动暂存；首次点击保存时才要求填写名称。右下角缩放百分比可以直接输入 25–200。
- 连线会即时标识并拒绝不兼容的端口；运行前检查必填值、数量、参数 Schema、素材归属、重复边和环路，运行中还会检查动态输入与下游输出。问题面板可定位到对应节点。需要改变数据类型时应安装或开发显式转换节点。
- 内置控制节点采用版本化 Flow 契约，端口显示名称不参与调度；无效执行器、透传来源或控制端口声明会在运行前被拒绝。

## 自动下载与许可证

插件不会联网下载模型、节点或其他代码。节点插件是受信任的本地 Python 代码，安装前应检查其来源、许可证和 `INSTALL.md`。
